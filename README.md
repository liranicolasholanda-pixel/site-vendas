# Limite do Mercado — Android

Aplicativo Android simples para acompanhar gastos no mercado. Defina um orçamento, adicione produtos e receba alertas ao chegar a 80% e 100% do limite.

## APK automático
Acesse **Actions → Build Android APK → Run workflow**. Ao concluir, abra a execução e baixe o artefato `limite-do-mercado-apk`.

O APK de depuração não é assinado para publicação na Play Store.
